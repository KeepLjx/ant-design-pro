# E1-1 冲突清单：mall-admin 后端 ↔ ant-design-pro 前端契约不一致点

> 生成依据：`mall/openapi/mall-admin.openapi.yaml`（由 mall-admin 后端源码 + 运行时 `/v3/api-docs/default` 校验）
> 处理原则：**不允许修改后端**，全部在 ant-design-pro 前端 adapter 层转换。
> 实现位置：`src/services/mall/adapter.ts`、`src/services/mall/client.ts`

## 对比结论（一致数 /6）

| # | 对比维度 | 后端（OpenAPI 实际返回） | 前端期望（ant-design-pro 约定） | 结果 |
|---|---------|------------------------|-------------------------------|------|
| 1 | 请求路径 + HTTP 方法 | POST `/admin/login`；GET `/product/list` | 相同 | ✅ 一致 |
| 2 | 请求参数命名/位置 | `username/password`（body）；`pageNum/pageSize/keyword/...`（query） | 相同 | ✅ 一致 |
| 3 | 响应外层包装 | `{ code, message, data }`，code=200 成功 | `{ success, data, errorMessage }` | ❌ 需 adapter（E1-1-01） |
| 4 | 分页结构 | `data: { list, pageNum, pageSize, totalPage, total }` | ProTable `{ data, current, pageSize, total, success }` | ❌ 需 adapter（E1-1-02） |
| 5 | 登录返回 | `data: { token, tokenHead }` | `{ status:'ok', currentAuthority }` + token 需持久化注入 | ❌ 需 adapter（E1-1-03） |
| 6 | 用户信息字段 | `{ username, icon, roles, menus }` | `{ name, avatar, access }` | ❌ 需 adapter（E1-1-04） |

**一致数 = 2 / 6**

## 冲突明细与 adapter 转换点

| 编号 | 冲突点 | 后端实际 | 前端约定 | adapter 转换点（代码位置） | 状态 |
|------|--------|---------|---------|---------------------------|------|
| E1-1-01 | 响应外层包装 | `code: 200` 表示成功；失败返回 `code: 500/401/404` | `success: boolean` | `client.ts mallRequest`：`code===200 → data`；否则抛 `MallBizError(code, message)` | ✅ 已实现 |
| E1-1-02 | 错误消息字段 | `message: "密码不正确"` | `errorMessage` / Error.message | `client.ts mallRequest`：`message → MallBizError.message` | ✅ 已实现 |
| E1-1-03 | 分页结构 | `data.list`（数组）、`data.pageNum`（1 起） | `data.data`、`data.current` | `adapter.ts toProductListResult`：`list→data`、`pageNum→current`、补 `success:true` | ✅ 已实现 |
| E1-1-04 | 登录返回 | `data.token`、`data.tokenHead`（如 "Bearer "） | `status:'ok'`；token 持久化并注入 `Authorization` 头 | `adapter.ts toLoginResult` + `client.ts` token 注入（tokenHead+token） | ✅ 已实现 |
| E1-1-05 | 用户信息字段 | `username`、`icon`、`roles[]`、`menus[]` | `name`、`avatar`、`access` | `adapter.ts toCurrentUser`：`username→name`、`icon→avatar`、`roles→access`（保留原字段） | ✅ 已实现 |

> 说明：后端 `java.util.Date` 经 Jackson 序列化为 ISO-8601 字符串（真实调用确认，
> 如 `"2023-01-10T07:49:38.000+00:00"`），与前端 dayjs 直接兼容，**不属于冲突项**。

## 验证

- adapter 转换点 5 处（E1-1-01 ~ E1-1-05）全部实现，无遗漏。
- **adapter 转换点与 E1-1 冲突清单一致率 = 5/5 = 100%**
- 真实调用：`POST /admin/login`（admin/123456）→ 200 + token；`GET /product/list`（携带 Authorization）→ 200 + 分页数据；前端 `/mall/product-list` 页面渲染成功。
